# 아이가 그린 그림일기와 AI 4컷 만화

## 현재 화면

왼쪽은 아이가 직접 그린 원본 그림과 확인한 일기를 합친 그림일기입니다. 오른쪽은 같은 일기의 사건·감정을 바탕으로 생성한 AI 4컷 만화입니다. 작은 화면에서는 그림일기 다음에 만화를 세로로 보여줍니다.

일기 문장은 아이가 사용한 낱말을 살려 짧고 자연스럽게 다듬습니다. 기본은 '-했다', '-갔다', '-좋았다' 같은 쉬운 일기체입니다. 보고서식 문장, 의도적인 맞춤법 오류, 과장된 감탄사·유아어를 만들지 않습니다. 말하지 않은 사건·감정·이유·교훈을 추가하지 않고 기존 source_ids 검토와 사용자 수정·확인 단계를 유지합니다.

## 사용 순서

1. 기존 서버를 종료하고 실제 AI 모드로 다시 실행합니다.
2. <http://127.0.0.1:8002/dev/voice>에서 마이크로 대화합니다.
3. 일시정지 · 마이크 끄기 → 대화 마치고 일기 쓰기를 누릅니다.
4. 생성된 일기를 읽고 필요한 부분을 수정한 뒤 확인 체크를 합니다.
5. 아래 그림판에서 마우스·트랙패드·손가락으로 그림을 그립니다. 색·선 굵기·지우개·되돌리기·다시 하기를 사용할 수 있습니다. 모두 지우기도 되돌리기로 복원할 수 있습니다.
6. 내 그림과 일기 합치기를 누릅니다. 왼쪽 그림일기가 완성됩니다. 이 합치기는 브라우저에서 처리하며 이미지 생성 API를 호출하지 않습니다.
7. 오른쪽 4컷 만화 만들기를 누릅니다. AI가 확인한 일기에서 장면을 나누고 컷을 한 장씩 생성·검토합니다.
8. 실패한 컷은 이 컷만 다시 만들기로 재시도합니다. 짧은 일기로 반복되는 컷은 원본 컷 이미지를 재사용합니다. 반복 컷에서 재시도해도 원본 컷만 요청하고 반복 컷을 함께 갱신합니다.
9. 그림일기 · 만화 파일 저장으로 그림이 포함된 HTML을 내려받거나, 인쇄 · PDF 저장으로 출력합니다. 만화 생성 전에도 직접 그린 그림일기를 저장할 수 있습니다.

## 그림 원본과 만화의 관계

직접 그린 그림은 PNG로 그대로 왼쪽에 배치합니다. 선·색을 AI가 고치거나 덮어쓰지 않습니다. 현재 이 그림은 브라우저 메모리에서만 합치며 외부 AI로 전송하지 않습니다.

만화의 이야기 근거는 확인한 일기입니다. 현재 Cloudflare FLUX.1 schnell 연결은 텍스트로 새 삽화를 만드는 방식이므로 원본 그림의 캐릭터·선을 그대로 복제하는 이미지 편집 기능은 아닙니다. 만화의 외모·장면 결과는 반드시 확인해야 합니다. 원문에 없는 사건·감정을 추가하지 않도록 생성·검토 프롬프트를 유지하며 자동 검토가 완전한 일치를 보장하지는 않습니다.

원문이 4개 사건보다 짧아도 새 사건·반전·결말로 채우지 않습니다. 같은 장면을 반복하고 화면과 내보낸 파일에 표시합니다. 4컷의 글은 확인한 일기를 나눈 원문 그대로입니다.

## 수정·취소·저장

- 일기를 고치면 확인 체크와 기존 만화는 해제됩니다. 직접 그린 선은 지우지 않습니다.
- 원본 그림을 더 그리거나 되돌리면 합치기를 다시 해야 합니다. 일기가 같으면 기존 만화를 재사용할 수 있습니다.
- 대화를 추가하면 일기와 결과 연결은 해제되며 새 대화로 일기를 다시 만듭니다. 그림판의 원본은 유지합니다.
- 만화 생성 실패나 재시도는 왼쪽 그림일기를 바꾸지 않습니다.
- 일부 컷이 실패해도 그림일기와 완료된 컷을 파일로 보관할 수 있습니다.
- 다운로드 파일에는 원본 PNG, 일기, 만화 이미지와 캡션이 포함됩니다. 텍스트는 HTML로 해석하지 않도록 이스케이프합니다.
- 브라우저 새로고침 전에 저장하세요. 날짜별 DB 저장과 기기 간 동기화는 BE 담당이며 현재 개발 화면에는 없습니다.

## FE·BE 연결

API 9개와 기존 JSON 계약은 바꾸지 않습니다.

```text
확인한 대화 → POST /api/diary → 부드러운 일기 초안 → 사용자 확인
아이 그림판 PNG + 확인한 일기 → 브라우저에서 왼쪽 그림일기 구성
같은 일기 → POST /api/visual-story (format=comic4)
         → POST /api/visual-story/image (format=comic4, 장면별)
         → 오른쪽 2×2 만화 배치
```

FE가 원본 PNG와 확인한 일기를 별도로 보존하고, BE가 사용자·날짜에 연결해 저장해야 합니다. 원본 그림을 AI 그림으로 덮어쓰면 안 됩니다. 현재 개발 화면의 저장 상태는 composed의 drawing/text와 illustrator.state입니다. 파일 저장은 이 두 상태를 합쳐 만듭니다.

## 변경 파일과 변수

| 파일 | 역할 |
| --- | --- |
| prompts.py | 아이 낱말을 살린 일기 문체와 근거 검사 |
| devtools/voice/drawing.mjs | 원본 선·그림판·되돌리기·PNG·두 칸 HTML 내보내기 |
| devtools/voice/illustration.mjs | comic4 선택, 4컷 생성, 반복 컷 재사용·재시도 |
| devtools/voice/app.js | 원본 그림일기 합치기와 만화 연결 |
| devtools/voice/index.html, style.css | 왼쪽 그림일기 / 오른쪽 만화 화면 |
| dev_voice.py | 개발용 그림판 모듈 제공 |

| 변수 | 의미 |
| --- | --- |
| drawingPad.history.strokes | 아이가 직접 그린 원본 선 목록 |
| history.past / future | 되돌리기·다시 하기 이력 |
| drawingPad.options | 색·굵기·색연필/지우개 선택 |
| composed.drawing | 직접 그린 원본 PNG 데이터 URL |
| composed.text | 사용자가 확인한 일기 |
| illustrator.state.format | 현재 만화 흐름에서는 comic4 |
| scene.reuse_scene_id | 반복 컷이 재사용할 원본 컷 ID |

추가 키나 패키지는 필요 없습니다. Groq는 대화·일기·장면 구성·검토, Cloudflare는 만화 이미지 생성에 사용됩니다. 실제 아동 대상 운영의 서비스 연령·데이터 조건은 별도 확인이 필요합니다.
