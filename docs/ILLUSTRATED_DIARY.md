# 대화에서 그림일기 만들기

## 사용 순서

1. `.env`에 Groq 키와 Cloudflare 토큰·계정 ID가 설정되어 있는지 `python check_setup.py`로 확인합니다. `ENABLE_VOICE_DEMO=1`이 필요합니다.
2. 기존 서버를 종료한 뒤 실제 AI 모드로 다시 실행합니다.
3. <http://127.0.0.1:8002/dev/voice>에서 마이크로 대화합니다.
4. 대화를 마칠 때 일시정지 · 마이크 끄기를 누르고 대화 마치고 그림일기 만들기를 누릅니다. 아직 전사 초안이 남아 있으면 내용을 먼저 확인해 보냅니다.
5. 생성한 일기를 읽고 잘못된 부분을 고칩니다. 일기에 언급하지 않은 사건이나 감정이 들어가지 않았는지 확인합니다.
6. 그림 수를 선택합니다. 기본은 최대 2장입니다. 원문 문장 수가 적으면 선택한 수보다 적은 그림을 만듭니다.
7. 위 내용이 내가 말한 내용과 맞아요에 체크하고 확인한 내용으로 그림 만들기를 누릅니다.
8. 그림일기 영역에 그림과 해당 장면의 글이 나타납니다. 모든 그림이 완료되면 그림일기를 먼저 보여주며 일기 글 보기 · 수정으로 원문을 다시 확인할 수 있습니다.
9. 생성에 실패하거나 원문 일치 검토에서 거절된 장면은 글을 유지합니다. 키·한도 등을 확인하고 이 장면만 다시 만들기를 선택합니다. 이미 완료된 그림은 다시 요청하지 않습니다.
10. 그림일기 파일 저장으로 그림이 포함된 HTML 파일을 저장합니다. 인쇄 · PDF 저장을 누른 뒤 Mac 인쇄 창에서 PDF로 저장할 수도 있습니다.

## 데이터 흐름

`확인한 대화 → POST /api/diary → 사용자 수정·확인 → POST /api/visual-story → 장면별 POST /api/visual-story/image → 그림+원문 캡션 표시`

새 API 키나 별도 유료 모델은 추가하지 않습니다. 기존 Groq 텍스트 모델이 일기·장면 구성·영문 이미지 묘사를 처리하고, Cloudflare가 그림을 생성하며, Groq 이미지 모델이 원문 일치를 검토합니다. 자동 검토가 사실 일치를 보장하지는 않으므로 최종 그림도 사용자가 확인해야 합니다.

그림 생성은 무료 사용량을 소모하고, 계정 플랜에 따라 비용이 발생할 수 있습니다. 버튼을 누른 뒤 장면별로 순서대로 요청하며 자동 반복·자동 재시도하지 않습니다. 한 장에 묘사·생성·검토 요청이 필요하므로 시간이 걸릴 수 있습니다. 브라우저의 이미지 요청 대기 한도는 6분입니다. 중지해도 이미 제공업체에 도착한 작업 자체나 과금이 취소되는 것은 아닙니다.

## 원문 유지와 실패 처리

- 일기 확인 전에는 그림 API를 호출하지 않습니다.
- 장면의 글은 서버가 나눈 확인된 원문 그대로 표시합니다. 표시용 캡션을 이미지 생성 모델이 새로 쓰지 않습니다.
- 일기를 수정하면 기존 그림은 화면에서 지우고 확인 체크를 해제합니다. 수정 전 그림을 새 일기와 섞지 않습니다.
- 대화를 추가하면 기존 일기·그림도 무효화됩니다. 새 대화로 다시 일기를 만듭니다.
- 그림 응답의 diary_hash, source_ids, caption이 현재 장면과 다르면 표시하지 않습니다.
- rejected/failed 응답은 그림을 만들었다고 표시하지 않습니다. 이미 완료된 장면과 모든 글은 유지합니다.
- 생성 중 중지하면 늦게 도착한 그림은 무시합니다. 남은 장면은 다시 만들기로 재개할 수 있습니다.
- 생성 중에는 일기 글·그림 수를 바꿀 수 없습니다.

## 저장과 출력

HTML 내보내기는 이미지 데이터와 글을 파일 안에 포함합니다. 스크립트나 외부 이미지 URL은 포함하지 않으며, 텍스트를 HTML로 해석하지 않도록 이스케이프합니다. 일부 그림이 실패한 상태에서도 완료된 그림이 한 장 이상 있으면 파일 저장이 가능하며, 빠진 장면에는 오류 안내와 글을 남깁니다.

파일의 생성 시각은 출력 파일을 만든 시각이며 사건이 일어난 날짜가 아닙니다. 현재 개발 화면은 날짜별 DB 저장 기능이 없습니다. 새로고침 전에 내려받아 보관하고, 영구 저장·사용자별 조회는 BE에서 연결합니다.

## 주요 변수

| 변수 | 의미 |
| --- | --- |
| illustrator.state | 확인한 일기·해시·장면별 그림 생성 상태 |
| illustrator.version | 중지·수정 전 비동기 결과를 무시하는 작업 번호 |
| diaryMessageCount | 현재 일기를 만든 시점의 대화 메시지 수 |
| diary-approved | 일기 내용을 사용자가 확인했는지 여부 |
| picture-count | 요청할 그림 수의 상한 |
| scene.status | waiting/generating/generated/rejected/failed/cancelled |
| scene.imageUrl | 검토를 통과한 PNG/JPEG 데이터 URL |
| scene.caption | 확인한 일기를 나눈 해당 장면의 원문 글 |

이 도구는 AI 담당자의 연결 검사용입니다. 제품 FE·BE 레포지토리와 API 계약은 유지하며, 화면 코드는 FE 담당자가 참고해 옮길 수 있습니다.
