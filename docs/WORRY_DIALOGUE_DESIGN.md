# 우냥이 고민 대화 설계

## 연구 근거와 적용 범위

Tuning in to Kids OnLine 무작위 대조 연구는 4~10세 자녀의 부모를 대상으로 감정 코칭, 공감과 감정 무시 반응 등을 평가했다. 부모 교육의 결과를 아동 AI 상담 효과로 일반화할 수 없다. 이 서비스는 경청·감정 인정·문제 해결 지원 원리를 대화 설계에 적용한다. 초록에서 확인한 연구 근거이며 원문 전체 검토와 서비스 효과 검증은 남아 있다.

- 연구 초록 https://pubmed.ncbi.nlm.nih.gov/39268375/
- UNICEF 경청·반영·아동에게 맞는 언어 안내 https://www.unicef.org/lac/en/parenting-lac/nurturing-care/how-communicate-effectively-young-child
- UNICEF 부모 교육 자료 https://www.unicef.org/lac/media/27656/file/The%20Art%20of%20Parenting.pdf

## 대화 동작

현재 발언과 앞선 대화를 바탕으로 경청, 감정 확인과 위로, 원하는 도움 확인, 작은 해결 방법, 실행 가능성 확인 중 하나를 선택한다. 단계는 내부 모델 출력이며 공개 API에는 추가하지 않는다. 아이가 방법을 요청하면 확인 질문을 반복하지 않고 작은 제안을 한다. 단순 친구 다툼은 정상 대화로 이어 간다. 안전 위협은 기존 needs_adult 안내를 따른다.

기존 고정 문장 선택을 맥락에 맞는 message 생성으로 바꾼다. 일반 응답은 reply이며 질문 횟수만으로 종료하지 않는다. 명시적인 종료 의사는 기존 finished 분기를 사용한다. 내부 모델 호출은 한 번, 제한 시간은 12초다. 기존 출력 토큰 상한을 사용한다.

출력은 최대 220자, 질문부호 최대 하나, 공백 응답 거부를 검사한다. 한 질문의 의미적 단일성, 공감의 적절성, 조언의 안전성과 사실성은 프롬프트만으로 보장할 수 없으므로 합성 대화 기반 실제 모델 평가가 필요하다.

## 장애와 운영

unavailable은 모델 비활성화 또는 호출·출력 검증 실패로 발생한다. 아이의 고민을 거절한 것으로 보이지 않도록 연결 문제 안내를 표시한다. 호출 실패 시 성공한 대화처럼 보정하거나 자동 재호출하지 않는다.

WORRY_ENABLE_MODEL=0 기본값과 BE의 WORRY_ENABLED=false 정책을 유지한다. 현재 운영 승인은 별도 팀 결정이다. 공개 요청/응답, 24개 메시지·8,000자 한도와 기록 보관 책임은 기존 계약을 따른다. needs_adult는 현재 BE에서 세션 종료로 처리되므로 그 후 대화 지속은 별도 계약 합의가 필요하다.

Mock 모드는 화면 확인용 고정 응답이다. 실제 모델의 공감·문맥 이해 품질을 나타내지 않는다. 로컬 테스트는 합성 모델 응답의 전달, 비활성화, 오류, 종료, 안전 안내 및 입력 제한을 확인한다.
